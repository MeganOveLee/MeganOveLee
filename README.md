### 🧱 Featured — Enterprise DS v1.0

> 전담 프론트엔드가 없는 엔터프라이즈 백오피스 화면을,
> 1인 퍼블리셔가 표준화하고 인계 가능한 상태로 유지하기 위한 디자인 시스템

- **CSS가 스타일을 소유** — 토큰(`--color-*`) → 컴포넌트 클래스(`.btn`, `.input` …). JSP 같은 레거시 화면에도 그대로 씁니다
- **브랜드 · 다크 모드 전환** — `<html class="theme-*">`, `<body class="dark-mode">` 한 줄
- **결정 기록(ADR)** — 컴포넌트마다 왜 이렇게 만들었는지 근거를 남깁니다
